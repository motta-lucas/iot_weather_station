# TIL - 2026-07-31 - Arduino - Setting up Arduino IDE

  

## 📚 What I've learned
<!-- Clear and Simple description of learning -->

  How to set up Arduino IDE to start working with it
  

## 🔧 How does it work?
<!-- Technical or Conceptual explanation -->
This is specific for NODEMCU ESP8266, but I figure it won't be much different for other micro controllers.
  
  

## 💻 Hands on

```

<!-- Codes, commmands ou practical cases -->
1. Open Arduino IDE
   
2. Go to *Files* > *Preferences*
   
3. On "Additional boards manager URL:" add the following
   
	   http://arduino.esp8266.com/stable/package_esp8266com_index.json

4. Go to *Tools* > *Board* > *Boards Manager*, look for "ESP8266" and click "Install" 

5. Go to *Tools* > *Board* > *esp8266* and look for *NODEMCU 1.0 (ESP-12E Module)*
   
   If it is in there, everything is ok
```
